	\section{Introducción y Contextualización}
	
	\subsection{Título del proyecto}
	Opalo E-Learning.
	\subsection{Justificación}
	Opalo E-Learning es relevante como herramienta en el contexto actual porque tiene como único objetivo la formación, desde la introducción hasta la comprensión más profunda del ámbito de conocimiento a tratar, en temas de interés para nuestros usuarios. Se diferencia de otras plataformas de aprendizaje porque aquí: no tratamos de vender humo, toda la formación es enteramente gratuita, y nos basamos en fuentes fiables y revisables.
	
	\subsection{Objetivos generales}
	
	El objetivo general de este proyecto es diseñar, desarrollar y desplegar una página web corporativa funcional y de alto rendimiento para una empresa especializada en servicios de formación. En él se han integrado las competencias técnicas de los módulos SMR2.
	
	Para lograrlo, se trabajó de manera estructurada en varios frentes clave. En primer lugar, se diseño una interfaz cómoda donde garantizamos una navegación fluida, incluso en dispositivos de bajo rendimiento, y sencilla de entender para todos los usuarios.
	
	De forma paralela, se elaboraron recursos educativos interactivos mediante H5P con la plantilla de \textit{Course Presentation}. El interés de éstos es que proporcionan un recurso de aprendizaje dinámico donde el alumno, además de leer y ver las imágenes de una diapositiva, tienen la posibilidad de evaluar sus conocimientos mediante los cuestionarios interactivos
	
	Posteriormente, se procedió a la implementación técnica de la web mediante herramientas consolidadas como Apache, XAMPP y Acrylic DNS Proxy, lo que permitió crear nuestro propio servidor web autoalojado de forma profesional y eficiente. 

	A lo largo de todo el proceso se documentó cada etapa de manera detallada, desde la planificación inicial hasta la entrega final, generando un registro completo que sirve como base técnica y metodológica.
	
	Finalmente, se preparó una exposición oral clara y profesional ante el jurado, en la que se presentó tanto la empresa como la página web desarrollada, destacando sus aspectos estratégicos, técnicos y de valor añadido.
	\subsubsection{Resumen}

	\begin{itemize}
		\item Diseñar una página web de forma responsiva y accesible para todos.
		\item 	Implementarla mediante herramientas como Apache, XAMPP y Acrylic DNS Proxy.
		\item 	Crear las presentaciones de H5P para la creación de los cursos.
		\item 	Documentar todo el proceso desde el principio hasta el final.
		\item 	Optimizar el código para que sea lo más ligero posible y compatible con todo tipo de dispositivos, incluso siendo éstos de bajo rendimiento.
		\item 	Por último, explicar a un jurado de forma oral nuestra empresa y página web.
	\end{itemize}
	
	\subsection{Identificación de necesidades}
	
	Hemos detectado que la realidad de muchas páginas web del \sout{sector tecnológico} (actualmente sector formativo) no cumplen con tres aspectos clave:
	
	\textbf{1. Diseño y desarrollo web:}
	
	Numerosas compañías eligen emplear plantillas estándar de WordPress o Wix, mientras que algunas otras ni siquiera poseen una página web profesional. Aquí proponemos un sitio web bien diseñado y agradable para el visitante.
	
	\textbf{2. Educar sobre los temas que se tratan:}
	
	Es frecuente que las empresas del mismo sector no proporcionen a sus posibles clientes toda la información necesaria para comprender la relevancia de sus servicios (aunque inicialmente se planificó el proyecto como una empresa del sector tecnológico, actualmente, estamos enfocados en el sector de la formación en Internet).
	
	Esto reduce la confianza y el interés del posible comprador, pues no comprende a qué se dedica la empresa. Demostrando compromiso con la transparencia, nuestro equipo está a su disposición para proporcionarle toda la información que tenemos. Por esta razón, disponemos de una sección dedicada a nosotros y otra de Contacto.
	
	\textbf{3. Rendimiento:}
	
	Una buena parte de las páginas web no se ajustan a los criterios de una carga veloz de todo el contenido.

	\section{Análisis técnico y diseño de la solución}
	\subsection{Requerimientos del sistema:}
	
	\subsubsection{Página de inicio}
	
	La página de bienvenida está diseñada para captar la atención del visitante desde el primer segundo y transmitir profesionalismo y confianza.
	
	Nada más acceder, un slider automático presenta de forma atractiva algunos de los cursos más relevantes, acompañado de un mensaje claro de posicionamiento. Inmediatamente después, el usuario se encuentra las secciones principales: formación disponible, formación próximamente y sobre nosotros. Al final de la página, se incluyen las secciones de patrocinadores y contacto.
	
	Esta estructura resuelve una necesidad clave en un sector altamente competitivo: comunica de forma efectiva y rápida qué es la empresa y qué valores ofrece, sin generar sobrecarga informativa. En un entorno donde los usuarios abandonan las páginas en pocos segundos si no encuentran interés inmediato, esta página consigue enganchar al visitante y diferenciarse claramente de la competencia.
	
	A diferencia de plataformas como edX o Udemy, que existen registro y pago para acceder a la mayoría de sus contenidos, nuestra web ofrece una experiencia abierta, sin barreras iniciales, lo que facilita el acceso inmediato a la información y reduce la fricción para el usuario.
	
	\noindent\textbf{{\large Solución implementada}}
	
	Esta experiencia se logra principalmente mediante un slider dinámico desarrollado con las librerías jQuery y Swiper, complementado con HTML, CSS y JavaScript puro. Este componente permite un desplazamiento fluido y atractivo de los cursos destacados.
	
	Justo debajo, un titular potente —“Líderes en formación online”— refuerza el posicionamiento de la empresa, mientras que bloques visuales estratégicos guían al usuario hacia las principales secciones. El cierre con patrocinadores y contacto consolida la confianza y facilita la conexión.
	
	\subsubsection{Sobre nosotros}
	
	Esta sección presenta de forma clara y cercana la historia de la empresa, su misión, visión y a las personas que integran el equipo.
	
	En sus inicios, la misión se centraba en impulsar la innovación para liderar las tecnologías emergentes de manera sostenible. Hoy, esa misión se ha consolidado en un propósito más concreto y realizable: ofrecewr los mejores servicios de formación en Internet.
	
	Esta sección resuelve uno de los principales desafíos de las empresas emergentes: la falta de credibilidad. Al mostrar quiénes están detrás del proyecto y cuál es su propósito real, se genera confianza y se construye una narrativa humana que conecta emocionalmente con el visitante, transmitiendo seriedad, buenas intenciones y trayectoria.
	
	\noindent\textbf{{\large Solución implementada}}
	
	La información se organiza mediante una atractiva línea del tiempo que marca los hitos más relevantes ya alcanzados, así como los objetivos y metas propuestas para el futuro. Este formato permite al usuario entender de un vistazo la evolución de la empresa y su proyección.
	
	Técnicamente, se desarrolló de manera eficiente utilizando únicamente HTML y CSS, tecnologías que resultaron más que suficientes para crear una presentación visual limpia y profesional.
	
	\subsubsection{Contacto}

	La sección de Contacto ofrece un canal directo y sencillo de comunicación mediante un formulario donde los visitantes pueden enviar sus dudas, sugerencias o consultas al equipo de desarrollo.
	
	Esta funcionalidad resuelve uno de los principales problemas en proyectos digitales: la falta de comunicación fluida. En un entorno donde las respuestas lentas pueden hacer perder oportunidades valiosas, esta seccción facilita un acceso inmediato y directo a expertos o posibles colaboradores que nos quieran ayudar en la corrección o elaboración de los contenidos formativos.
	
	\noindent\textbf{{\large Solución implementada}}
	
	Se diseño un formulario claro, limpio y fácil de usar, desarrollado integramente con HTML y CSS. A través de este formulario los mensajes se envían directamente al correo del equipo, permitiendo una gestión ágil de las comunicaciones sin necesidad de complejas integraciones adicionales.
	
	Esta solución mantiene la simplicidad y la eficiencia, garantizando una experiencia cómoda para el usuario y una respuesta rápida por parte del equipo.
	
	\subsubsection{Patrocinadores}
	
	La sección de Patrocinadores muestra los logotipos de las organizaciones y empresas que respaldan y financian el proyecto, otorgando visibilidad y reconocimiento a quienes contribuyen a su desarrollo.
	
	Esta sección cumple una doble función estratégica: por un lado, reconoce públicamente el apoyo recibido y, por otro, refuerza la credibilidad del proyecto al demostrar que cuenta con el respaldo de entidades relevantes. En un sector tan competitivo y costoso como el de la formación online, esta visibilidad ayuda a fortalecer la imagen de la empresa y abre puertas a futuras alianzas y oportunidades de financiación.
	
	La presentación se realiza de forma limpia y profesional, destacando los patrocinadores de manera visual y respetuosa, lo que contribuye a transmitir solidez y confianza en el proyecto.
	
	\subsubsection{Aviso legal}
	
	El Aviso Legal de Opalo E-Learning está diseñado con el objetivo de transmitir claridad, transparencia y confianza desde el primer momento. Nada más acceder, el usuario encuentra un texto estructurado, profesional y fácil de leer que informa de forma completa sobre la identidad de la empresa, las condiciones de uso del sitio web y las políticas de privacidad y protección de datos.
	
	Esta página cumple una función estratégica fundamental: genera seguridad jurídica tanto para la empresa como para el visitante, al tiempo que proyecta una imagen de seriedad, cumplimiento normativo y respeto por los derechos de los usuarios. En un entorno digital donde la confianza es clave, un aviso legal claro y accesible refuerza la credibilidad de la marca y reduce posibles fricciones o dudas.
	
	\noindent\textbf{{\large Solución implementada}}
	
	El texto ha sido redactado en un tono profesional pero cercano, evitando lenguaje excesivamente jurídico que pueda resultar intimidante. Se prioriza la legibilidad mediante párrafos cortos, encabezados descriptivos y un diseño limpio que facilita la comprensión.
	
	Esta página refleja los valores de OPALO E-LEARNING: transparencia, respeto por la privacidad del usuario y cumplimiento riguroso de la normativa vigente (RGPD y LOPDGDD). Todo ello contribuye a construir una relación de confianza sólida con nuestros visitantes y alumnos desde el primer contacto.

Sin registro, de forma sencilla y rápida.”

Cada curso se presenta con un título impactante y una breve descripción que despierta curiosidad y conecta emocionalmente con el lector, invitándole a descubrir más.
	
	\noindent\textbf{{\large Solución implementada}}
	
	La página combina un diseño limpio y moderno con descripciones potentes y evocadoras. Cada curso utiliza un tono inspirador y cercano que transforma temas complejos en experiencias atractivas. Los botones “Saber más” facilitan la navegación hacia las fichas individuales de cada programa, manteniendo al usuario dentro de un flujo natural de descubrimiento.

	\subsubsection{Entretenimiento}
	
	La sección de Entretenimiento ofrece una experiencia interactiva y educativa que combina diversión con aprendizaje práctico. Su objetivo es demostrar de forma amena que la programación no solo sirve para crear aplicaciones serias, sino también para desarrollar experiencias lúdicas y atractivas.
	
	Nada más acceder, el visitante se encuentra con un juego sencillo pero funcional: “Cuadrado que se Mueve”, un clásico arcade minimalista totalmente desarrollado en Python con la librería Pygame. El juego permite mover un cuadrado por la pantalla utilizando las teclas de dirección o las teclas WASD, manteniendo los límites de la ventana.
	
	\noindent\textbf{{\large Solución implementada}}
	
	El juego ha sido desarrollado íntegramente en Python utilizando la librería Pygame, una de las herramientas más populares y accesibles para crear videojuegos 2D.
	
	El código está estructurado de forma clara y profesional, con secciones bien diferenciadas (inicialización, datos del juego, bucle principal, control de eventos, límites de pantalla y renderizado). Incluye buenos comentarios que facilitan su comprensión.
	
	El usuario puede:
	
	\begin{itemize}
		\item Jugar directamente en la página a través de un componente interactivo (iframe).
		\item 	Ver el código fuente completo.
		\item 	Descargarlo o copiarlo para experimentar y modificarlo.
	\end{itemize}
	
	Esta combinación de juego más el código visible convierte la página en una excelente herramienta de aprendizaje interactivo.
	
	En definitiva, la sección de Entretenimiento refuerza la idea de que aprender programación puede ser divertido, accesible y creativo, alineándose perfectamente con la filosofía de OPALO E-LEARNING de formación práctica y sin barreras.

Esta organización permite al visitante hacerse una idea completa y estructurada del programa en menos de un minuto.

	\subsection{Diseño de la infrestructura de red}
	
	Para el desarrollo de este proyecto es muy necesario tener en cuenta estos conceptos básicos.
	
	\subsubsection{DHCP}
	
	Por sus siglas: Dynamic Host Configuration Protocol. Es un servicio que asigna direcciones IP y otros
	parámetros de red como puertas de enlace, DNS o tiempos de concesiones (leases) de forma automática a
	los dispositivos cuando se conectan a la red. Evitando así que cada equipo tenga que configurar estos
	parámetros de forma manual en cada conexión facilitando la gestión de redes con muchos dispositivos de
	forma centralizada.
	
	\subsubsection{DNS}
	
	Por sus siglas: Domain Name System. Es un sistema que se encarga de traducir direcciones de dominio
	legibles por humanos (en nuestro caso, opalo.learning) en direcciones IP numéricas (en nuestro caso
	[recordemos que usamos una IP de loopback] 127.0.01)

	\subsubsection{Solución por descarte}
	
	La solución que hemos planteado a este problema es la de tener una propia página web donde concretar cuál
	es nuestra actividad, los servicios que ofrecemos, las ventajas sobre otros competidores, precios, detalles de
	contacto con correo electrónico, etc. Para comprobar si es una solución válida vamos a ayudarnos con una
	serie de preguntas que se presentan a continuación:
	
	La primera pregunta que nos hacemos es: si la página web puede resolver completamente el problema de
	visibilidad. Una web profesional, con información corporativa, un portafolio de servicios, formularios de
	contacto y optimización básica para motores de búsqueda, permite a clientes potenciales descubrir nuestra
	empresa.
	
	Por ejemplo, proveedores como Goya Soluciones Informáticas pueden crear webs personalizadas para
	pymes, mientras que Digital Hand Made ofrece soluciones de comercio electrónico que potencian ventas
	online, ampliando la visibilidad hacia transacciones directas. Multinacionales como Indra o Accenture España van más allá, integrando marketing digital, análisis de datos e inteligencia artificial para maximizar el alcance, e Hiberus destaca por diseñar experiencias digitales únicas que atraen a los usuarios, creando interfaces más intuitivas y atractivas.
	
	Sin embargo, la falta de visibilidad no se resuelve solo con una web estática. El problema abarca necesidades más amplias, como estrategias de marketing continuo (SEO avanzado, campañas en redes sociales,
	publicidad pagada) y adaptaciones a cambios en algoritmos o comportamientos de usuarios. Una web sin
	estos complementos podría no generar interés en tiempo real ni alcanzar audiencias en plataformas externas,
	motores de búsqueda especializados, (Google Académico) o agregadores de reseñas locales como Trustpilot.
	Proveedores locales como Alerce, centrados en software para logística, podrían limitarse a webs básicas sin
	estrategias integrales, mientras que gigantes como Kyndryl, enfocados en cloud, podrían ofrecer soluciones
	sobredimensionadas, generando costos innecesarios.
	
	Así, aunque una web contratada mejora la visibilidad, no cubre todas las facetas del problema sin servicios
	adicionales, lo que la hace una solución parcial.
	
	Otro aspecto crucial es si disponemos del conocimiento necesario para implementar la solución al contratar
	un proveedor. Al externalizar, la experiencia técnica recae en la empresa contratada, liberándonos de dominar el desarrollo web.
	
	Proveedores como Onegolive, con más de 15 años de experiencia, ofrecen consultoría para alinear la
	solución con nuestras necesidades, entregando documentación clara sobre el CMS u otras tecnologías
	usadas.
	
	Capgemini, enfocada en ingeniería digital, proporciona manuales detallados y asistencia directa, mientras que NTT Data, utilizando métodos ágiles, asegura procesos organizados y claros para transferir conocimientos al cliente. Esto nos permite gestionar la web tras la entrega, actualizando contenido o revisando métricas básicas.
	
	Sin embargo, esta transferencia depende de la calidad del proveedor. Empresas como GMV, enfocadas en
	sectores como aeroespacial, podrían priorizar proyectos complejos y ofrecer documentación limitada para pymes, mientras que locales como Infoter podrían proporcionar guías básicas que no cubran SEO avanzado o
	buena comunicación con el cliente.
	
	La dependencia del proveedor para actualizaciones futuras también limita nuestra autonomía, especialmente
	si no incluye formación exhaustiva. Por tanto, aunque el conocimiento está disponible, la solución tiene
	reservas, ya que nuestra capacidad de supervisión y gestión a largo plazo podría ser limitada.
	La innovación es otro factor a considerar. Un proveedor externo puede incorporar elementos como chatbots
	con IA o la integración con APIs de redes sociales.
	
	Hiberus, por ejemplo, se encarga de crear experiencias digitales innovadoras facilitando la navegación
	intuitiva, mientras que Ayesa integra IA en plataformas que automatizan la actualización del contenido, y DXC
	Technology usa automatización para optimizar visibilidad en la red. Estas innovaciones, como analítica
	predictiva o personalización de contenido, podrían servir como modelo para otras empresas.
	
	Sin embargo, para una empresa de dos personas, el presupuesto podría restringirse a una web estándar con
	plantillas predefinidas, reduciendo la innovación. Proveedores como Alerce, enfocados en logística, podrían
	limitarse a personalizaciones enfocadas en ese sector, y multinacionales como Atos España, con énfasis en
	infraestructuras digitales, podrían implementar soluciones técnicamente demasiado complejas que no se
	adapten a contextos de pymes. La innovación, aunque posible, depende de los recursos y no siempre es
	escalable sin ajustes, haciendo la solución parcialmente innovadora.
	
	La viabilidad técnica de una web contratada es indiscutible. Los proveedores de la lista dominan tecnologías
	modernas (HTML5, CSS3, JavaScript, CMS como WordPress) y estándares como HTTPS o diseño
	responsive.
	
	Integra ofrece webs dinámicas y escalables, es decir, páginas web que pueden actualizar su contenido
	automáticamente o interactuar con los usuarios y además soportan muchos usuarios activos. Capgemini
	asegura páginas que funciones incluso con alta demanda, y GMV trabaja preparando ante ciberataques y
	optimizando el rendimiento.
	
	Sin embargo, la elección del proveedor importa: Kyndryl, centrado en cloud, podría no priorizar webs simples
	(más bien infraestructuras críticas como bancos), y locales como Goya podrían carecer de experiencia en
	personalizaciones avanzadas, como bases de datos dinámicas.
	
	A pesar de estas diferencias, la viabilidad técnica está asegurada, ya que todos los proveedores relevantes
	pueden entregar una web funcional para visibilidad. En términos de recursos, contratar un proveedor es
	viable, ya que delegamos el desarrollo técnico, requiriendo solo comunicación inicial y aprobación de diseños.
	
	Infoter ofrece soluciones asequibles para pymes, con integración de marketing, mientras que NTT Data usa
	plataformas low-code, como por ejemplo OutSystem, para reducir costos. Digital Hand Made permite servicios
	a medida desde diseño web básico hasta soluciones completas como e-commerce, ciberseguridad y correo
	profesional en la nube, ajustándose al presupuesto.
	
	Sin embargo, multinacionales como Accenture podrían exigir presupuestos elevados, y locales como Goya
	implican costos recurrentes para mantenimiento, como por ejemplo los servicios de hosting y software de
	gestión de clientes.
	
	Finalmente, la calidad de la web contratada depende de su capacidad para ofrecer funcionalidades
	(navegación intuitiva, diseño responsive), fiabilidad (hosting estable), eficiencia (carga rápida) y efectividad (aumentar visibilidad).
	
	Digital Hand Made asegura webs optimizadas para la transformación digital, Indra entrega soluciones
	integrales con documentación, guías de usuario y cumplimiento normativo, y Hiberus prioriza la usabilidad,
	centrándose en interfaces intuitivas y atractivas visualmente. Sin embargo, la efectividad requiere
	mantenimiento continuo y estrategias complementarias, no siempre incluidas.
	
	Proveedores como Ayesa podrían enfocarse en proyectos grandes, generando soluciones excesivas como
	sistemas de gestión de contenido o servicios en la nube, y locales como Alerce podrían ofrecer servicios más
	centrados en el sector logístico con sistemas de gestión de almacenes. La calidad es alta, pero parcial si no
	se garantiza soporte a largo plazo o SEO avanzado.
	
	\subsubsection{Conclusiones}
	
	Por último, reflexionando sobre estas evaluaciones, contratar un proveedor externo tiene claras ventajas:
	experiencia técnica, innovación potencial y calidad profesional, con empresas como Hiberus, Digital Hand
	Made o NTT Data destacando por soluciones robustas.
	
	Sin embargo, para una empresa de dos personas, las limitaciones son significativas. Proveedores locales
	como Goya o Infoter ofrecen soluciones asequibles pero a menudo estándar, con personalización limitada y
	costos recurrentes para actualizaciones. Multinacionales como Indra, Accenture o Capgemini, aunque
	técnicamente superiores, priorizan proyectos grandes, con costos elevados y procesos burocráticos que
	desalinean con nuestras necesidades simples. Empresas como Kyndryl o GMV, enfocadas en la nube o
	sectores específicos, podrían no centrarse en una web básica.
	
	La dependencia de terceros reduce nuestro control, y la comunicación constante puede retrasar iteraciones.
	Por ello, concluimos que desarrollar la web internamente es la mejor opción. Con un presupuesto mínimo
	(dominio y hosting asequibles), herramientas accesibles como WordPress y aprendizaje autónomo, podemos
	crear una web funcional, personalizada y escalable. Aunque requiere tiempo, nos permite mantener control
	total, iterar rápidamente y complementar con acciones propias, como redes sociales, para maximizar la
	visibilidad, alineándonos perfectamente con nuestros recursos limitados.

	\section{Implementación y desarrollo (el núcleo técnico)}
	
	\subsection{Configuración de servicios de red:}
	
	Para la instalación del servidor web se requiere Apache, en este caso, hemos optado por instalar XAMPP que
	contiene Apache y una fácil configuración.
	
	Cuando instalamos XAMPP en nuestro sistema, por defecto, se crea una carpeta y sus diferentes binarios,
	carpetas y archivos de configuración. Ésta es creada en Windows \verb|C:\xampp\htdocs| o en Linux \verb|/etc/xampp|.
	
	Dentro de la carpeta de XAMPP se crea la carpeta \verb|htdocs|. Aquí es donde se guarda la carpeta que contiene nuestro
	sitio web del proyecto.
	
	Para que Apache sepa qué carpeta servir según el nombre que reciba, editamos el archivo:
	
	\begin{verbatim}
		C:\xampp\apache\conf\extra\httpd-vhosts.conf
	\end{verbatim}

	Escribimos lo siguiente:
	
	\label{Apache}
	\begin{lstlisting}[language=, caption={httpd-vhosts.conf}, label=lst:Apache]
		<VirtualHost *:80>
		ServerName opalo.learning
		DocumentRoot "C:/xampp/htdocs/opalo"

	\subsubsection*{Bajo impacto energético de usar servidores optimizados}
	
	El uso de servidores optimizados de bajo impacto energético es una parte importante para alcanzar los ODS
	de la Agenda 2030 y más recientemente todavía lo es más con el uso de Inteligencia Artificial.

	Algunas de las características clave para alcanzar esta reducción en el consumo de energía son:
	\begin{itemize}
		\item Hardware eficiente con procesadores de bajo consumo.
		\item 	Tecnologías de virtualización (OpenNebula o VMWare) o de contenedores (Docker) que permiten modular los recursos según las necesidades en cada momento.
		\item 	Centros de datos ubicados en zonas más frías en países tales como Islandia o Noruega reduciendo el consumo de energía por aires acondicionados.
		\item 	Utilización de código optimizado para aumentar la eficiencia con la que trabajan los servidores.
		\item 	Una CDN (o red de entrega de contenidos) para almacenar copias de los datos consultados más frecuentemente para estar más cerca del usuario final y conectarse menos al servidor principal.
	\end{itemize}

	\subsubsection{HTML: El lenguaje fundamental de la web}
	
	El HTML (HyperText Markup Language) es el lenguaje estándar utilizado para crear y estructurar las páginas web. Los navegadores lo interpretan y lo convierten en la interfaz visual que los usuarios experimentan a diario. Gracias a ello, el HTML se ha consolidado como la tecnología base más extendida de internet, permitiendo combinar de forma estructurada textos, imágenes, sonidos, vídeos y otros elementos multimedia.
	
	A diferencia de los medios tradicionales (como libros o revistas), el HTML incorpora una capacidad transformadora: los hipervínculos. Esta funcionalidad permite conectar documentos entre sí, generando una red de información interrelacionada que revolucionó el acceso y la distribución del conocimiento.
	
	\noindent\textbf{{\large Orígenes y evolución del HTML}}

	El HTML nació con un propósito principalmente divulgativo y académico, orientado a compartir documentos científicos de manera sencilla. Nadie previó que la web se convertiría en un entorno multimedia, comercial y de ocio masivo. Esta visión inicial limitada generó ciertas carencias estructurales que se han ido resolviendo a lo largo del tiempo.
	
	Hoy en día, el HTML ya no sigue un modelo de versiones numeradas estáticas. Se mantiene como un Living Standard (estándar vivo) gestionado por el WHATWG. La base de este estándar moderno es HTML5, que introdujo importantes mejoras en semántica, multimedia, accesibilidad y capacidades para aplicaciones web. Este enfoque evolutivo continuo permite incorporar nuevas funcionalidades sin necesidad de grandes actualizaciones formales.
	
	A pesar de su evolución algo irregular en el pasado, el HTML actual se complementa perfectamente con tecnologías auxiliares que resuelven sus limitaciones originales:
	
	\begin{itemize}
		\item CSS (Cascading Style Sheets) para el diseño y la presentación visual.
		\item 	JavaScript para la interactividad y el comportamiento dinámico.
	\end{itemize}
	
	Estas tecnologías permiten organizar, optimizar y automatizar el funcionamiento de las páginas web de manera mucho más eficiente.
	
	\noindent\textbf{{\large Herramientas para crear páginas web}}
	
	Crear una página HTML sigue siendo técnicamente sencillo: se trata de un archivo de texto plano con extensión \verb|.html|.

	Comience con herramientas simples como el Bloc de Notas (Windows) o editores básicos equivalentes. Esta simplicidad ayuda a concentrarse en el código y comprender los fundamentos del lenguaje.
	
	Entre los editores recomendados más avanzados se reconocen:
	
	\begin{itemize}
		\item Visual Studio Code: Ligero, potente, con miles de extensiones, vista previa en vivo y excelente soporte para HTML, CSS y JavaScript.
		\item 	Otras opciones sólidas: Notepad++, Sublime Text u otros editores especializados que aumentan notablemente la productividad una vez dominados los conceptos básicos.
	\end{itemize}
	
	\noindent\textbf{{\large HTML: Sintaxis, etiquetas y estructura básica}}
	
	El HTML se basa en un sistema de etiquetas (tags) que permiten estructurar y dar significado al contenido de una página web.
	
	La mayoría de las etiquetas siguen una estructura de apertura y cierre. Todo el contenido situado entre ellas recibe las características definidas por esa etiqueta.
	
	Ejemplo práctico:
	
	Las etiquetas <strong> y </strong> definen un texto con importancia (tradicionalmente mostrado en negrita).
	
	Código:
	\begin{verbatim}
		<strong>Este texto está en negrita</strong>
	\end{verbatim}
	
	Resultado:
	
	\begin{quotation}
		Este texto está en negrita.
	\end{quotation}
	
	Las etiquetas <p> y </p> definen un párrafo.
	
	Código:
	
	\begin{verbatim}
	<p>Hola, estamos en el párrafo 1</p>
	<p>Ahora hemos cambiado de párrafo</p>
	\end{verbatim}
	
	Resultado:
	
	\begin{quotation}
	Hola, estamos en el párrafo 1.
	
	Ahora hemos cambiado de párrafo.
	
	\end{quotation}
	
	\noindent\textbf{{\large Estructura general de un documento HTML}}
	
	Todo documento HTML debe seguir una estructura básica y bien definida:
	
	\begin{verbatim}
		<!DOCTYPE html>
		<html lang="es">
			<head>
				<!-- Contenido del encabezado (metadatos) -->
			</head>
			<body>
				<!-- Contenido visible de la página -->
			</body>
		</html>
	\end{verbatim}
	
	Un documento HTML se divide principalmente en dos secciones:
	
	\textbf{{\small 1. El encabezado (<head>)}}
	
	Aquí se incluye información meta que no se visualiza directamente en la página, pero es esencial para los navegadores y motores de búsqueda. Ejemplos comunes:
	
	\begin{itemize}
		\item El título de la página (<title>)
		\item 	Codificación de caracteres
		\item 	Descripciones, palabras clave y metadatos
		\item 	Enlaces a hojas de estilo (CSS), scripts, etc.
	\end{itemize}
	
	\textbf{{\small 2. El cuerpo (<body>)}}
	
	Es la sección donde se coloca todo el contenido que el usuario verá: textos, imágenes, vídeos, formularios, menús y demás elementos.
	
	\subsubsection{CSS: Separando contenido y presentación}
	
	Las CSS (Cascading Style Sheets o Hojas de Estilo en Cascada) surgieron para resolver una limitación fundamental del HTML: la mezcla entre contenido y presentación.
	
	Mientras que el HTML se encarga de estructurar y dar significado al contenido (qué es un título, un párrafo, una imagen, etc.), las CSS controlan cómo se muestra ese contenido: colores, tipografías, espaciados, distribuciones, tamaños, animaciones y comportamientos responsivos.
	
	\noindent\textbf{{\large ¿Qué son las CSS?}}

	Las CSS son un lenguaje específico diseñado para definir la presentación visual de documentos escritos en HTML. Permiten a desarrolladores y diseñadores crear reglas de estilo que se aplican de forma consistente en una página o en todo un sitio web.
	
	Ventajas clave:
	
	\begin{itemize}
		\item Separación clara de responsabilidades: El HTML se centra en la estructura semántica y las CSS en el diseño.
		\item 	Mayor control y eficiencia: Un solo archivo CSS puede definir el aspecto de cientos o miles de páginas.
		\item 	Mantenibilidad: Cambiar el diseño de todo un sitio (por ejemplo, actualizar colores corporativos o tipografía) se reduce a modificar unas pocas líneas en la hoja de estilos.
		\item 	Consistencia: Garantiza que todos los elementos del mismo tipo (títulos, botones, enlaces…) se muestren de forma uniforme.
		\item 	Flexibilidad: Múltiples hojas de estilo pueden aplicarse a una misma página, combinándose según un sistema de prioridades conocido como “cascada”.
	\end{itemize}
	
	\noindent\textbf{{\large El concepto de “Cascada”}}
	
	El término Cascading hace referencia a que los estilos se aplican en capas y siguen un orden de prioridad. Un mismo elemento puede recibir estilos desde diferentes fuentes (hoja de estilos del navegador, hoja del autor y estilos inline), y las CSS resuelven los conflictos aplicando reglas de cascada, especificidad y orden de declaración.
	
	\noindent\textbf{{\large Evolución frente al HTML antiguo}}
	
	En versiones antiguas de HTML era común incluir información de formato directamente en las etiquetas (atributos como \verb|color|, \verb|size|, \verb|face|, etc.). Esto generaba código repetitivo, difícil de mantener y que impedía a los usuarios modificar la visualización según sus necesidades (por ejemplo, personas con discapacidad visual).
	
	Con las CSS modernas:
	
	Las etiquetas HTML se utilizan exclusivamente para definir estructura y significado (<h1>, <p>, <article>, etc.).
	
	Toda la información de presentación se mueve a las hojas de estilo.ç
	
	Se mejora drásticamente la accesibilidad, el rendimiento y la adaptabilidad a diferentes dispositivos.
	
	\noindent\textbf{Ejemplo práctico:}
	
	En lugar de escribir:
	
	\begin{verbatim}
		<h1><font color="blue" size="6">Título</font></h1>
	\end{verbatim}
	
	Se escribe:
	
	\begin{verbatim}
		<h1>Título</h1>
	\end{verbatim}
	
	Y en un archivo CSS separado:
	
	\begin{verbatim}
	h1 {
		color: #0033a0;
		font-size: 2.5rem;
		font-family: 'Inter', sans-serif;
	}
	\end{verbatim}
	
	En resumen, las CSS son una de las tecnologías más importantes del desarrollo web actual. Junto con HTML y JavaScript forman el trío fundamental para crear experiencias digitales profesionales, mantenibles, accesibles y visualmente atractivas.
	
	\subsubsection{JavaScript: Añadiendo interactividad e inteligencia a la web}
	
	JavaScript es un lenguaje de programación que permite crear comportamientos dinámicos e interactivos dentro de las páginas web. Mientras que el HTML se encarga de la estructura y las CSS del diseño visual, JavaScript aporta la capa lógica e interacción, transformando páginas estáticas en experiencias dinámicas y funcionales.
	
	El navegador del usuario es el encargado de interpretar y ejecutar el código JavaScript directamente en el lado cliente. Esto significa que gran parte de la lógica y las funcionalidad pueden ejecutarse sin comunicarse constantemente con el servidor, ofreciendo mayor velocidad y una experiencia más fluida.
	
	\noindent\textbf{{\large Capacidades principales de JavaScript}}
	
	JavaScript ofrece dos grandes vertientes de valor:
	
	\noindent\textbf{{\small Efectos y contenidos dinámicos}}
	
	Permite crear elementos que se mueven, cambian de apariencia, se muestran u ocultan según condiciones, galerías interactivas, sliders, animaciones y actualizaciones de contenido en tiempo real sin recargar la página.
	
	\noindent\textbf{{\small Interactividad con el usuario}}
	
	Responde a las acciones del usuario (clics, desplazamiento, escritura, gestos táctiles, etc.) para ejecutar funciones específicas: validación de formularios, calculadoras, menús desplegables, carritos de compra, juegos simples, dashboards interactivos y aplicaciones web completas.
	
	Gracias a su evolución, JavaScript moderno es un lenguaje robusto que soporta programación asíncrona, manipulación avanzada del DOM, consumo de APIs, almacenamiento local, y una enorme cantidad de frameworks y librerías (React, Vue, Angular, etc.) que facilitan el desarrollo de aplicaciones web profesionales a gran escala.
	
	En resumen, JavaScript convierte al desarrollador en el verdadero controlador de la experiencia del usuario. Dominar este lenguaje es esencial para crear páginas web modernas, interactivas y competitivas.
	
	\noindent\textbf{{\large Ejemplos prácticos y rápidos}}
	
	En esta sección final de la introducción a JavaScript veremos varios ejemplos sencillos pero útiles que demuestran la potencia del lenguaje y su capacidad para añadir interactividad con muy poco código.
	
	Estos ejemplos sirven como muestra práctica de lo que se puede lograr rápidamente y ayudan a comprender mejor las posibilidades de este lenguaje.
	
	\noindent\textbf{{\small Abrir una ventana secundaria}}
	
	Con una sola línea de JavaScript es posible abrir una nueva ventana del navegador sin barras de herramientas ni menús:
	
	\begin{verbatim}
	<a href="#" 
		onclick="window.open(
			'https://www.google.com',
			'google',
			'width=800,
			height=600,
			menubar=no,
			toolbar=no,
			scrollbars=yes'
		); return false;">
		Abrir Google en ventana nueva 
	</a>
	\end{verbatim}
	
	Este tipo de funcionalidad permite crear ventanas emergentes personalizadas, aunque debe usarse con moderación debido a los bloqueadores de ventanas emergentes de los navegadores modernos.
	
	\noindent\textbf{{\small Mensaje de bienvenida}}
	
	Podemos mostrar un mensaje emergente cuando el usuario carga la página:
	
	Las etiquetas \verb|<script></script>| nos sirven para introducir código JavaScript dentro de un archivo HTML. Alternativamente, se puede colocar en el \verb|<head></head>| un \verb|<script src="script.js"></script>| que apunte a un archivo JavaScript independiente.
	
	\begin{verbatim}
	<script>
		window.onload = function() {
			alert("¡Bienvenido a nuestro sitio web!");
		};
	</script>
	\end{verbatim}
	
	\noindent\textbf{{\small Mostrar la fecha actual}}
	
	Este script muestra la fecha de hoy en el lugar donde se inserte, lo que ayuda a transmitir que el sitio está actualizado:
	
	\begin{verbatim}
	
	<p>Fecha de hoy: <span id="fecha"></span></p>
	
		<script>
			document.addEventListener('DOMContentLoaded', function() {
				const fecha = new Date();
				document.getElementById('fecha').textContent = fecha.toLocaleDateString('es-ES', {
					weekday: 'long',
					year: 'numeric',
					month: 'long',
					day: 'numeric'
				});
			});
	</script>
	\end{verbatim}
	
	\noindent\textbf{{\small Botón para volver atrás}}

	Crear un botón que simule el comportamiento del botón “Atrás” del navegador es muy sencillo:
	
	\begin{verbatim}
		<button onclick="history.back()">← Volver a la página anterior</button>
	\end{verbatim}
	
	Estos ejemplos, aunque básicos, ilustran la facilidad con la que JavaScript puede enriquecer una página web, responder a acciones del usuario y manipular el contenido dinámicamente.

	\subsubsection{Cómo funciona nuestro juego de Python}
	
	El juego que hemos desarrollado es muy sencillo.
	
	A continuación, lo explicamos línea por línea.
	
	\begin{verbatim}
		import pygame
		import sys
	\end{verbatim}
	
	\verb|import pygame|: Trae la librería Pygame para poder hacer juegos y gráficos.
	
	\verb|import sys|: Sirve para poder cerrar el programa correctamente.
	
	\begin{verbatim}
		pygame.init()
	\end{verbatim}
	
	Esta línea \textit{enciende} Pygame. Es obligatoria. 
	
	\begin{verbatim}
		NEGRO = (0, 0, 0)
		BLANCO = (255, 255, 255)
		ROJO = (255, 0, 0)
		AZUL = (0, 100, 255)
	\end{verbatim}
	
	Creamos las variables para cada uno de los colores que vamos a utilizar en el juego.
	
	\begin{verbatim}
		ANCHO = 800
		ALTO = 600
	\end{verbatim}
	
	Definimos el tamaño de la ventana del juego en píxeles: 800 píxeles de ancho y 600 de alto.
	
	\begin{verbatim}
		pantalla = pygame.display.set_mode((ANCHO, ALTO))
		pygame.display.set_caption("Cuadrado que se Mueve vs enemigo")	
	\end{verbatim}
	
	La primera línea crea la ventana del juego.
	
	La segunda pone el título arriba de la ventana.
	
	\begin{verbatim}
		reloj = pygame.time.Clock()
	\end{verbatim}
	
	Creamos un "reloj" que controla la velocidad del juego (para que no vaya demasiado rápido).
	
	\begin{verbatim}
		tamano = 60
		x = ANCHO // 2 - tamano // 2
		y = ALTO // 2 - tamano // 2
		velocidad = 8
	\end{verbatim}
	\verb|tamano = 60|: El cuadrado medirá 60x60 píxeles.
	\verb|x e y|: Son las coordenadas donde está el cuadrado.
	La fórmula \verb|ANCHO // 2 - tamano // 2| lo coloca en el centro de la pantalla.
	\verb|velocidad = 8|: Cuántos píxeles se mueve cada vez (mientras mantengas la tecla presionada).
	
	\begin{verbatim}
		tamano_enemigo = 50
		ex = 100
		ey = 100
		velocidad_enemigo = 4
	\end{verbatim}
	
	\verb|tamano_enemigo|: Tamaño del enemigo (también 50x50).
	\verb|ex| y \verb|ey|: Posición inicial del enemigo (en la esquina superior izquierda).
	\verb|velocidad\_enemigo = 4|: Velocidad del enemigo (más lento que el jugador).
	
	\begin{verbatim}
		game_over = False
		fuente = pygame.font.SysFont(None, 60)
	\end{verbatim}
	
	\verb|game_over| = False: Variable que controla si el juego ha terminado.
	\verb|fuente|: Crea una fuente de texto grande para mostrar el mensaje de Game Over.
	
	\begin{verbatim}
		while True:
	\end{verbatim}
	
	El bucle se repita de forma constante, 60 veces por segundo, mientras el juegos esté abierto.
	
	\begin{verbatim}
		for evento in pygame.event.get():
		if evento.type == pygame.QUIT:
		pygame.quit()
		sys.exit()
	\end{verbatim}
	
	Revisa si el jugador ha cerrado la ventana con la X. Si lo hace, cierra el juego correctamente.
	
	\begin{verbatim}
		if not game_over:
	\end{verbatim}
	
	Todo el movimiento y lógica del juego solo se ejecuta si todavía no hemos perdido.
	
	\begin{verbatim}
		teclas = pygame.key.get_pressed()
		
		if teclas[pygame.K_LEFT] or teclas[pygame.K_a]:
			x -= velocidad
		if teclas[pygame.K_RIGHT] or teclas[pygame.K_d]:
			x += velocidad
		if teclas[pygame.K_UP] or teclas[pygame.K_w]:
			y -= velocidad
		if teclas[pygame.K_DOWN] or teclas[pygame.K_s]:
			y += velocidad
	\end{verbatim}
	
	El movimiento del jugador se produce cuando se pulsan unas teclas determinadas.
	
	\begin{verbatim}
		x = max(0, min(x, ANCHO - tamano))
		y = max(0, min(y, ALTO - tamano))
	\end{verbatim}
	
	Evita que el jugador salga de la pantalla usando max() y min() (forma más corta y limpia).
	
	\begin{verbatim}
		if ex < x:
				ex += velocidad_enemigo
			elif ex > x:
				ex -= velocidad_enemigo
		
			if ey < y:
				ey += velocidad_enemigo
			elif ey > y:
				ey -= velocidad_enemigo
	\end{verbatim}
	
	El enemigo se mueve hacia el jugador:
	
	\begin{itemize}
		\item Si está a la izquierda > se mueve a la derecha.
		\item 	Si está arriba > se mueve hacia abajo, etc.
	\end{itemize}
	
	\begin{verbatim}
		if (x < ex + tamano_enemigo and x + tamano > ex and
			y < ey + tamano_enemigo and y + tamano > ey):
			game_over = True
	\end{verbatim}
	
	Si los dos cuadrados se tocan, el juego termina (\verb|game_over = True|).
	
	\begin{verbatim}
		pantalla.fill(NEGRO)
	\end{verbatim}
	
	Pinta toda la pantalla de negro (borra lo que había antes).
	
	\begin{verbatim}
		pygame.draw.rect(pantalla, ROJO, (x, y, tamano, tamano))
		pygame.draw.rect(pantalla, BLANCO, (x, y, tamano, tamano), 4)
	\end{verbatim}
	
	Dibuja al jugador (cuadrado rojo con borde blanco).
	
	\begin{verbatim}
		pygame.draw.rect(pantalla, AZUL, (ex, ey, tamano_enemigo, tamano_enemigo))
	\end{verbatim}
	
	Dibuja al enemigo (cuadrado azul).
	
	\begin{verbatim}
		if game_over:
			texto = fuente.render("¡GAME OVER!", True, ROJO)
			pantalla.blit(texto, (ANCHO//2 - texto.get_width()//2, ALTO//2 - 50))
	\end{verbatim}
	
	Si perdiste, muestra el texto \verb|¡GAME OVER!| en grande y centrado.
	
	\begin{verbatim}
		pygame.display.flip()
		reloj.tick(60)
	\end{verbatim}
	
	\begin{itemize}
		\item \verb|flip()|: Actualiza la pantalla para ver los cambios.
		\item 	\verb|tick(60)|: Mantiene el juego a 60 frames por segundo.
	\end{itemize}
